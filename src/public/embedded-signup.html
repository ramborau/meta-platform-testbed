Onboard a WhatsApp Business Account

This runs the real Embedded Signup flow: the customer authenticates, picks or creates a business portfolio and WABA, verifies a phone number, and grants this app access to it. The window returns an authorization code, which the server exchanges for a business-scoped token and then subscribes to the WABA.

What the server does with the code

  1. GET /oauth/access_token?client_id&client_secret&code — no redirect_uri, unlike normal OAuth. Returns a business integration system-user token.
  2. GET /debug_token — reads granular_scopes to learn which WABA the token is bound to.
  3. POST /{waba-id}/subscribed_apps — this is what turns on message webhooks. Skip it and you get nothing.
  4. POST /{phone-number-id}/register — registers the number on Cloud API with a 6-digit PIN (optional here).
  5. GET /{waba-id}/phone_numbers — resolves the Phone Number ID you will send with.
