Privacy Policy

This URL exists so the Meta App Dashboard accepts the app configuration. This is an internal development and testing tool, not a consumer product.

What this application is

A developer testbed used to exercise Meta's Graph API, Marketing API, WhatsApp Cloud API, Instagram Messaging and Messenger Platform webhooks. It is operated by the app owner for their own testing.

What data is processed

When a webhook fires, the payload Meta delivers is held in the server's memory so a developer can inspect it. This may include a sender's platform-scoped ID, display name, and message content. Access tokens obtained through Facebook Login or Embedded Signup are held in memory for the life of the process and are used only to call Meta APIs on the connecting user's behalf.

Retention

Nothing is written to a database or to disk. Events live in a bounded in-memory buffer capped at a few hundred records, and every record is discarded when the process restarts or redeploys. There is no analytics, no third-party sharing and no advertising use of this data.

Deletion

Because no data is persisted, a restart erases everything. A formal request can be made through the Data Deletion Callback registered for this app, which returns a confirmation code and status URL.
