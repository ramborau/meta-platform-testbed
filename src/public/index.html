Wiring checklist

      
The order that actually works. Steps 5 and 7 are the two people forget, and they are why webhooks silently never arrive.

      
    
        
  • 1.
    App Dashboard → App Settings → Basic: copy App ID and App Secret into the Render environment (META_APP_ID, META_APP_SECRET), then set Privacy Policy, Terms and Data Deletion URLs from the list above.
    • 
        
  • 2.
    Add Facebook Login for Business → Settings → paste the OAuth Redirect URI above into Valid OAuth Redirect URIs.
    • 
        
  • 3.
    Add the products you want: WhatsApp, Messenger, Instagram, Marketing API.
    • 
        
  • 4.
    For each product → Configuration → Webhooks → Edit: paste that product's Callback URL and the Verify Token, then Verify and Save.
    • 
        
  • 5.
    Subscribe to the fields after verifying — an empty field list means a verified URL that receives nothing. WhatsApp: messages. Instagram: messages, comments. Page: messages, messaging_postbacks, feed.
    • 
        
  • 6.
    WhatsApp → create an Embedded Signup configuration under Facebook Login for Business → Configurations, and set WA_EMBEDDED_CONFIG_ID in Render.
    • 
        
  • 7.
    Subscribe the app to each asset: WABA, Page and ad account each need their own /subscribed_apps call. Use the buttons on the channel tabs.
    • 
        
  • 8.
    Add yourself under App Roles → Roles, and for WhatsApp add test recipient numbers — in dev mode you can only message allow-listed numbers.
    •
