How this differs from the WhatsApp flow

    
Login variation cannot be changed once a configuration exists, which is why this is a second configuration rather than a setting.

    
    
      
  • •
    Login variation: General — not WhatsApp Embedded Signup.
    • 
      
  • •
    No extras sent to FB.login. setup, featureType and sessionInfoVersion are Embedded Signup only. Sending them against a General configuration is what makes a WhatsApp screen appear in a flow that should not have one.
    • 
      
  • •
    Assets: Pages, ad accounts, Instagram accounts, pixels. WhatsApp accounts are not requested, so nothing WhatsApp-related is granted.
    • 
      
  • •
    Same server path. The code exchange, debug_token asset discovery and subscription wiring are identical — WhatsApp discovery simply returns nothing.
